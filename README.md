# Clipboard History Tray

[English Version](./README.en.md)

> **Linguagem / Stack:** `C# (.NET 4.8)` | **Autor:** `piercer`

## O que faz

App de bandeja do Windows (System Tray) que guarda histórico do Ctrl+C para cópia rápida.

## Como executar

```bash
build.bat  # ou execute piercer_clipboard-history-tray.exe
```
